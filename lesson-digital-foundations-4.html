Working with Digital Tools

Before you build digital skills, it helps to understand the environment where those skills are used.

What are digital tools?

Digital tools are applications, programs and online services that help people complete tasks, solve problems, communicate and create things.

Different tools are designed for different purposes. Learning to identify the right tool can make your work faster, clearer and more organized.

The important idea

Digital skill is not about using the largest number of applications. It is about knowing which tool can help you accomplish a particular task effectively.

Common digital tools

Documents Word-processing tools can help you write letters, reports, applications, notes and other documents.
Spreadsheets Spreadsheet tools can help organize information, perform calculations and work with structured data.
Cloud storage Cloud storage can help you save, organize and access files from supported devices and locations.
Task and collaboration tools These tools can help individuals and teams organize work, share information and keep track of tasks.

Choose the right tool

Start with the task you need to complete. Ask what result you want, what information you need to work with and whether you need to work alone or with other people.

Practical example

If you need to calculate monthly expenses, a spreadsheet is usually more suitable than a basic text document because it can organize numbers and perform calculations.
