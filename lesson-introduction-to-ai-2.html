How AI Learns From Data

Before you start using AI tools, it helps to understand what artificial intelligence actually is and what it can do.

What is data?

Data is information that can be collected, stored and analyzed. It can include text, numbers, images, audio, measurements and many other types of information.

AI systems can use data to identify patterns and relationships that help them perform particular tasks.

The important idea

AI does not simply "know" things in the same way a person does. Many AI systems learn patterns from examples in data and use those patterns to produce an output.

A simple example

Imagine an AI system designed to recognize pictures of cats. It can be trained using many examples of images that have been identified as containing cats and images that do not.

During training, the system adjusts its internal parameters so that it can become better at recognizing patterns in new examples.

Training data Examples used to help an AI system learn patterns related to a particular task.
Patterns Relationships or features in data that an AI system can use when producing an output.
New input Information the system receives after training and uses to produce a prediction, classification or generated result.
Output The result produced by the AI system based on the input and patterns it has learned.
Why data quality matters

If the data used to develop an AI system is incomplete, inaccurate, poorly represented or unsuitable for the task, the system's results can also be unreliable. More data does not automatically mean better data.

Training is not the same as understanding

An AI system can become very good at recognizing patterns without having human-like understanding of the world. This is one reason people should review important AI outputs rather than automatically accepting them.
